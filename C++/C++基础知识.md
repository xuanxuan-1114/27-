# C++三大特性
封装，继承，多态
## **封装**
把数据和操作打包在类里，通过public/private/protected控制访问权，外部只能通过接口操作，不能直接改内部数据。
public：成员所有人可以访问。
private：成员外部不可访问。
protected：成员子类可以访问。
## **继承**
子类复用父类的属性和方法，在原有功能基础上扩展，避免重复代码。
子类自动拥有父亲的非私有成员，可以重写父类方法来改变行为。比如定义 `Animal` 基类，派生出 `Dog`、`Cat`，共享 `name` 属性但各自实现不同的 `speak()` 方法。
## **多态**
同一个接口，不同对象调用表现不同。分编译时多态（函数重载，模板）和运行时多态（虚函数+继承）。
**编译时多态（静态绑定）**：函数重载、运算符重载、模板。编译阶段确定调用哪个函数。
**运行时多态（动态绑定）**：通过虚函数实现。基类指针/引用指向派生类对象时，调用的是派生类的重写版本，而不是基类版本。
# 指针和引用
**指针**是**存储地址的独立变量**，可以重新赋值，可以为空，支持算术运算，但需要手动管理内存。
**引用**是变量的别名，必须初始化，不能为空、绑定后不能更改，编译器不为其分配独立存储空间。
# 结构体（struct）和类（class）
C++ 中 struct 和 class 在语法能力上完全等价，区别只有两个默认行为：struct 成员和继承默认 public，class 默认 private。另外模板参数只能用 `class` 或 `typename`，不能用 `struct`。工程惯例上，struct 用于纯数据聚合，class 用于有封装行为的类型。
# 结构体（struct）和联合体（union）
struct 的所有成员各自占用独立内存，sizeof 是所有成员大小之和（加对齐填充）。union 的所有成员共享同一块内存，sizeof 等于最大成员的大小，同一时刻只有一个成员有效。struct 支持继承、虚函数、完整的面向对象能力。union 不能继承、不能有虚函数、不能有引用成员，成员永远是 public。
# 关键字static和const
## static的四种用法
1. **局部静态变量**：生命周期延长到程序结束，但作用域仍在函数内。只初始化一次，后续调用保留上次的值。
2. **文件作用域的 static**：限制符号为内部链接，其他 `.cpp` 文件无法通过 `extern` 访问，实现文件级私有。
3. **类的静态成员变量**： 属于类本身而非某个对象，所有对象共享同一份，必须在类外定义（C++17 起可用 `inline static` 类内定义）。
4. **类的静态成员函数**：没有 `this` 指针，不能访问非静态成员，可通过 `类名::函数名()` 直接调用。
## const的四种用法
1. **修饰普通变量**：标记为只读，赋值会编译报错。
2. **修饰指针**：`const` 在 `*` 左边修饰值（底层 const，指向的内容不可改），在 `*` 右边修饰指针本身（顶层 const，指针不可改指向别处）。`const int* const p` 则两者都不可改。
3. **修饰引用**：`const int& ref = x` 表示不能通过 ref 修改 x，常用于函数参数——避免拷贝又保证不修改。
4. **修饰成员函数**：承诺不修改对象的任何非 `mutable` 成员，const 对象只能调用 const 成员函数。
# 关键字volatile
类型修饰符，用于防止编译器对变量进行优化，确保每次访问都直接从内存读取最新值。
正常情况下，编译器看到一个变量在两次读取之间没有写操作，会认为"值没变"，直接用寄存器里缓存的旧值代替第二次内存读取。对普通变量这没问题，例如硬件寄存器或被ISR修改的变量。
# inline函数和#define宏的区别
**#define宏**：预处理阶段处理，纯文本替换。没有类型检查，不遵守作用域，无法调试，可能产生多次求值 bug。
**inline函数**：编译阶段处理，是真正的函数。有类型检查，遵守作用域，可以调试，参数只求值一次。
# 关键字auto和关键字decltype
auto和decltype都是C++11引入的新型推导关键字
auto通过**初始化表达式推导变量类型**，编译器根据变量的初始值自动确定其数据类型。
```cpp
int main(){
auto x = 42;        //推断 x 为 int
auto y = 3.14;      //推断 y 为 double
auto z = "hello";   //推断 z 为 const char*


}
```
decltype**用于获取表达式的精确类型，不同于与auto，他不会立即对变量求值**。 
```c++ 
//推导变量类型
int x = 5;
decltype(x) y = 10;//y的类型与x相同。即int

//推导函数返回类型
int foo() {
	return 42;
}

decltype(foo()) f;//f的类型是int

//推导复杂表达式的类型
std::vector<int> v = {1, 2, 3, 4, 5};   
decltype(v.size()) sz; // sz 的类型是std::vector<int>::size_type
```
**注意** 在引用处理上，auto默认剥离引用，decltype保留引用
```cpp
const int& crx = x;
auto y = crx;       // y 的类型是int
decltype(crx) a = x;// a 的类型是const int&
```
# sizeof和strlen
**sizeof**是编译器运算符，关注类型信息，返回类型/变量占用的字节数（包含‘\0’）。
**strlen**是运行时函数，关注内存内容，从头遍历到第一个‘\0’停止，返回字符个数（不包含‘\0’）。使用类型仅限char* / char[]
```cpp
char arr[]="hello"; //sizeof(arr)=6(数组类型char[6]),strlen(arr)=5
char* ptr ="hello"; //sizeof(ptr)=8(64位系统指针大小),strlen(ptr)=5
sizeof看的是类型，strlen只看内容
```
**注**：**数组退化**，数组作为函数参数传递时，退化为指针。`函数内sizeof(arr)` 得到的指针大小为8。
**中间`\0`**:
```cpp
char s[] = {'a', '\0', 'b', 'c'};
//sizeif(s) = 4,strlen(s) = 1
```
# 浮点数比较
浮点数不能用`==`直接比较，二进制浮点数无法精确表示所有十进制小数。比如 `0.1` 在二进制中是无限循环小数，存储时必须截断，产生表示误差。
正确做法用误差容忍度`epsilon`比较:判断两个浮点数的差的绝对值是否小于某个阈值，而不是判断是否严格相等。
IEEE 754 单精度浮点数用 32 位存储：1 位符号、8 位指数、23 位尾数。尾数只有 23 位有效数字（约 7 位十进制精度），任何超出这个精度的信息都会被截断。
0.1转成二进制是0.0001100110011...（0011 无限循环）存储时必须在 23 位处截断。
**比较方法**：绝对无法比较法：`|a - b| < epsilon`适合数值范围已知且固定的场景（比如颜色值 0~1、像素坐标）。
相对误差比较：`|a - b| / max(|a|, |b|) < epsilon`按比例衡量误差。
混合方法：先用绝对误差处理接近 0 的情况，再用相对误差处理一般情况。实际项目中最常用。
# 局部变量，全局变量，静态局部变量
**局部变量**：定义在函数/代码块内，在栈上分配，函数调用时压栈、返回时弹栈，速度快但生命周期短。未初始化时值不确定（随机值）。
**全局变量**：定义在所有函数外，作用域为整个翻译单元，存储在静态存储区（数据段或 BSS 段），生命周期贯穿整个程序，默认零初始化。
**静态局部变量**：定义在函数内用 `static` 修饰，作用域限于该函数（外部不可访问），存储在静态存储区（数据段或 BSS 段），但生命周期贯穿整个程序，只在第一次执行到定义语句时初始化一次，之后保持上次的值。
# C++四种类型转换
- **`static_cast`**：编译时转换，用途最广，不做运行时检查
- **`dynamic_cast`**：运行时转换，专用于继承体系的安全向下转换，失败返回 `nullptr`
- **`const_cast`**：功能单一，只改 `const`/`volatile` 属性
- **`reinterpret_cast`**：最危险，比特位重解释，不做任何检查
