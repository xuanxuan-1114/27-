# 数据类型
## **精确宽度类型**
头文件`stdint.h`(C)或`cstdint.h`(C++)
`uint8_t` 无符号8位整数
`uint16_t`无符号16位整数
`uint32_t`无符号32位整数
8位占一个字节，`uint8_t`可表示0~255。
**好处**：确定性与可移植性，内存空间效率，与硬件寄存器直接交互
**为什么在嵌入式系统中最好不用int**
int由平台决定位宽，在AVR上是16位的，但是移植到STM32平台，int是32位的。
# 补码
现代计算机通常使用补码表示有符号整数。
正数的补码与二进制相同
5 = 0000 0101
负数的补码：
1. 写出对应正数的二进制
2. 所有位取反
3. 加1
-5的补码：
5的二进制 0000 0101
按位取反   1111 1010
加一          1111 1011
# 整数溢出
无符号整数溢出按照模2^n运算
有符号整数溢出在C狱中属于未定义行为
# `.`和`->`的区别
普通结构体变量使用点运算符
结构体指针使用箭头运算符
# 指针
```c
uint32_t value = 100; 
uint32_t *p = &value;
```
- `value`：保存数值100；
- `&value`：取得value的地址；
- `p`：保存value的地址；
- `*p`：访问该地址中的数据
**指向常量的指针**：
```c
const uint8_t *p;
```
不能通过 `p` 修改它指向的数据，但可以让 `p` 指向其他地址。
**常量指针**
```c
uint8_t * const p = buffer;
```
`p`不能指向其他地址，但可以修改指向的数据。
**指向常量的常量指针**
```c
const uint8_t * const p = buffer;
```
既不能改变指针指向，也不能通过该指针修改数据。
# 位运算
`&`       与             两个位都为1时，结果才为1
`|`       或             两个位都为0时，结果才为0
`^`       异或          两个位相同为0，相异为1
`~`       取反          0变1，1变0
`<<`     左移          各二进位全部左移若干位，高位丢弃，低位补0
`>>`     右移          各二进位全部右移若干位，高位补0或符号位补齐
