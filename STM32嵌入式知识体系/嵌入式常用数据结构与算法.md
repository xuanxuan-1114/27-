# 链表
链表由多个节点组成，每个节点包含：数据域，指向下一个节点的指针。
```c 声明
typedef struct Node 
{ uint32_t data; 
  struct Node *next;
} Node_t;
```
节点在内存中不必连续。

# 排序算法
## 冒泡排序
冒泡排序重复比较相邻元素，把较大的元素逐渐移动到数组后面。
```c
void BubbleSort(uint16_t *array, uint16_t length)
{
    if ((array == NULL) || (length < 2U)) {
        return;
    }

    for (uint16_t i = 0U; i < length - 1U; i++) {
        bool swapped = false;

        for (uint16_t j = 0U; j < length - 1U - i; j++) 
        {
            if (array[j] > array[j + 1U]) {
                uint16_t temp = array[j];
                array[j] = array[j + 1U];
                array[j + 1U] = temp;
                swapped = true;
            }
        }

        if (!swapped) {
            break;
        }
    }
```
## 选择排序
每次从未排序区域中选择最小元素，放到前面。
```c
void SelectionSort(uint16_t *array, uint16_t length)
{ 
	if (array == NULL) 
	{ 
		return;
	} 
	for (uint16_t i = 0U; i < length; i++)
	{ 
		uint16_t min_index = i; 
		
		for (uint16_t j = i + 1U; j < length; j++) 
		{ 
			if (array[j] < array[min_index])
			{ 
				min_index = j; 
			} 
		} 
		if (min_index != i) 
		{ 
			uint16_t temp = array[i]; 
			array[i] = array[min_index]; 
			array[min_index] = temp; 
		} 
	} 
}
```
## 插入排序
把每个元素插入前面已经有序的区域
```c
void InsertionSort(uint16_t *array, uint16_t length)
{
    if (array == NULL) {
        return;
    }

    for (uint16_t i = 1U; i < length; i++) {
        uint16_t key = array[i];
        int32_t j = (int32_t)i - 1;

        while ((j >= 0) &&
               (array[j] > key)) {
            array[j + 1] = array[j];
            j--;
        }

        array[j + 1] = key;
    }
}
```
