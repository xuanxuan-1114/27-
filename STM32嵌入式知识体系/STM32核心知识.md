# STM32最小系统组成
STM32最小系统是指能够支持STM32微控制器正常运行的基本硬件电路。它通常包括电源电路、时钟电路、复位电路、程序下载接口以及启动模式选择电路。
**电源**：STM32通常工作在3.3V电压下，电源电路通过LDO将5V降压至3.3V。输入和输出滤波电容用于稳定电压，避免电压波动影响系统运行。
**时钟电路**： 时钟电路为MCU提供运行所需的时钟信号，通常由晶振和起振电容组成。常用8MHz晶振，支持倍频操作。三个内部时钟，两个外部时钟。
**复位电路**：复位电路确保MCU在上电或异常情况下能够正确启动。STM32支持上电复位、手动复位和程序复位。
**程序下载接口**：stlink，jlink。
**启动电路**： STM32通过BOOT引脚决定启动位置，支持主闪存启动，系统存储器启动和内置SRAM启动。
## STM32启动过程
上电或复位
    ↓
读取向量表
    ↓
设置主栈指针MSP
    ↓
进入Reset_Handler
    ↓
初始化.data和.bss
    ↓
执行SystemInit()
    ↓
执行C/C++运行库初始化
    ↓
进入main()
## 向量表
程序启动地址处存放一张中断向量表。
## MSP
Main Stack Pointer,主栈指针。
## Boot模式
STM32通过BOOT引脚决定启动位置
BOOT0                           BOOT1                      启动区域
0                                      任意                           主Flash
1                                        0                              系统寄存器
1                                        1                              SRAM
# 时钟系统
## STM32F103主要时钟源
High Speed Internal（HSI），内部高速时钟。通常为8MHz
High Speed External（HSE），外部高速时钟。

Low Speed Internal（LSI），内部低速时钟。频率大约为40kHz，误差可能较大。主要用于：独立看门狗IWDGLRTC的低精度时钟源。
Low Speed External(LSE)，外部低速晶振。主要用于RTC。32.768Hz，经过15次二分频后得到1Hz。
## PLL倍频
用于把输入时钟倍频
STM32F103常用最高系统频率为72 MHz。8MHz x 9 = 72 MHz
## 系统时钟树
HSI/HSE
   ↓
PLL或直接选择
   ↓
SYSCLK
   ↓
AHB预分频
   ↓
HCLK
   ├── Cortex-M3内核
   ├── SRAM
   ├── DMA
   └── APB1/APB2预分频
          ├── PCLK1
          └── PCLK2
## 常见时钟名称
| 时钟      | 含义              | 常见配置/MHz |
| ------- | --------------- | -------- |
| SYSCLK  | 系统时钟源输出         | 72       |
| HCLK    | AHB总线时钟、CPU常用时钟 | 72       |
| PCLK1   | APB1外设时钟        | 36       |
| PCLK2   | APB2外设时钟        | 72       |
| ADCCLK  | ADC时钟           | 12       |
| TIMxCLK | 定时器时钟           |          |

- USART2、USART3；
- I²C1、I²C2；
- SPI2；
- CAN；
- PWR、BKP
### APB2常见外设

如果APB预分频为1： TIM*x*CLK=PCLK*x*

如果APB预分频不为1：TIM*x*CLK=2 x PCLK*x* 
# GPIO
GPIO是General Purpose Input/Output，即通用输入输出接口。
## GPIO输入模式
**浮空输入**：引脚既不内部上拉，也不内部下拉。
**上拉输入**：内部通过电阻弱连接到高电平。未按下：高电平；按下接地：低电平。
**下拉输入**：内部通过电阻弱连接到地。未按下：低电平；按下接3.3v：低电平。
**模拟输入**:关闭数字输入部分，减少干扰和功耗。ADC引脚应配置为模拟输入。
## GPIO输出模式
**推挽输出**：内部具有上拉和下拉驱动管，可以主动输出高电平和低电平。
适用LED，蜂鸣器，普通数字输出，SPI时钟和数据输出
**开漏输出**：只能主动输出低电平，输出高电平时实际上处于高阻态，需要上拉电阻把线路拉高。
适用IIC，多设备共享信号线，电平转换，线与逻辑。
# 中断系统
中断是CPU暂时停止当前程序，转去处理紧急事件，处理完成后再返回原程序的机制。

## 终端与轮询
**轮询**：CPU不断检查外设状态。
**终端**：UART收到数据后主动通知CPU。
## NVIC
Nested Vectored Interrupt Controller，嵌套向量中断控制器。
主要负责：
- 启用和关闭中断；
- 设置中断优先级；
- 管理中断嵌套；
- 保存中断挂起状态
## 抢占优先级和响应优先级
**抢占优先级**：决定一个中断能否打断另一个正在执行的终端。
**响应优先级**：当多个相同抢占优先级的中断同时等待时，决定谁先执行。
**注意**：优先级数越小，优先级越高。
## EXTI外部中断
GPIO电平变化可以通过EXTI产生中断
触发方式：：上升沿，下降沿，双边沿
## 中断服务函数设计原则
中断中适合：
- 读取外设数据；
- 清除中断标志；
- 保存数据；
- 设置标志；
- 释放信号量；
- 通知任务
中断中不适合：
- `HAL_Delay()`；
- 长时间循环；
- 复杂浮点运算；
- 大量串口打印；
- 阻塞等待；
- 动态内存分配；
- 执行完整业务流程。
# 定时器
定时器可以对输入的时钟进行计数，并在计数值达到设定值时触发中断。
## STM32定时器分类
**基本定时器**：主要用于定时和触发DAC等功能。
**通用定时器**：支持定时，输出比较，输入捕获，PWM，编码器接口。TIM2、TIM3、TIM4属于常见通用定时器。
**高级定时器**：除普通功能外，还支持互补PWM，死区时间，刹车输入，电机控制。
## PSC和ARR
- PSC：Prescaler，预分频器；
- ARR：Auto-Reload Register，自动重装载寄存器。
![[定时器.png]]
## 输入捕获
输入捕获用于记录外部信号边沿到来时的计数器值。
应用：
- 测量频率；
- 测量周期；
- 测量脉宽；
- 超声波测距；
- 读取转速信号。
## 输出比较
当定时器计数值等于CCR寄存器时，产生比较事件。
可以用于：
- 精确改变输出引脚；
- 产生单次脉冲；
- 定时触发某个事件；
- 软件调度。
# PWM
脉冲宽度调制。PWM信号周期固定，通过改变高电平持续时间控制平均输出效果。主要参数：周期；频率；占空比；脉宽。

# UART
用异步收发器。“异步”表示通信双方没有共享时钟线，需要提前约定：波特率；数据位；校验方式
## 波特率
波特率表示每秒传输的符号数量。在普通UART二进制通信中，可以近似理解为每秒传输的位数。
## 接收方式
**查询方式接收**：
```c
HAL_UART_Receive(UART_HandleTypeDef *huart, uint8_t *pData, uint16_t Size, uint32_t Timeout);
```
特点：使用简单，函数可能阻塞，不适合持续告诉接收。
**中断方式接收**：
```c
HAL_UART_Receive_IT(UART_HandleTypeDef *huart, uint8_t *pData, uint16_t Size)
```
使用HAL单字节中断接收时，回调完成后通常要重新启动下一次接收。
**DMA接收**：
```c
HAL_UART_Receive_DMA(UART_HandleTypeDef *huart, uint8_t *pData, uint16_t Size)
```
适合：连续数据；高波特率；批量数据；降低CPU中断频率。
## UART和USART的区别
UART只支持异步通信。
USART除了异步通信外，还可以支持同步通信。
STM32中的USART通常也可以工作在普通UART异步模式下。
# IIC
一种同步、串行、双线通信总线。
两根信号线：SCL时钟线，SDA数据线
iic支持：多主机，多从机，通过地址选择设备，ACK应答，同一总线挂载多个设备。
## 为什么需要上拉电阻
I²C引脚使用开漏结构，只能主动拉低，不能主动输出高电平。
## IIC时序基本单元
起始条件：SCL高电平期间，SDA从高电平切换到低电平。
终止条件：SCL高电平期间，SDA从低电平切换到高电平。
普通数据传输期间，SDA通常在SCL低电平时改变（发送），在SCL高电平时保持稳定（读取）。
从设备地址7位，第8位表示方向位，0表示主设备向从设备写数据，1表示主设备向从设备读数据。
# SPI
SPI是Serial Peripheral Interface，是一种同步、串行、通常全双工通信接口。支持一主多从。
基本信号线：
SCK：时钟线；
MOSI：主机发送、从机接收；
MISO：主机接收、从机发送；
CS/NSS：片选。
## SPI时序基本单元
启示条件：SS从高电平切换到低电平。
终止条件：SS从低电平切换到高电平。
## CPOL和CPHA
**CPOL**：时钟极性。
决定SCK空闲电平：
CPOL=1：空闲高电平；
CPOL=0：空闲低电平。
**CPHA**：时钟相位。
决定在第一个还是第二个有效边沿采样。
### 如何判断CPOL和CPHA
如果起始的SCLK的电平是0，那么CPOL=0，如果是1，那么CPOL=1，然后看数据采样时刻，即时序图数据线上的数据那个矩形区域的中间所对应的位置，对应到上面SCLK时钟的位置，对应着是第一个边沿或是第二个边沿，即CPHA是0或1。
## SPI四种模式
| 模式     | CPOL | CPHA | 空闲电平 |
| ------ | ---- | ---- | ---- |
| Mode 0 | 0    | 0    | 低    |
| Mode 1 | 0    | 1    | 低    |
| Mode 2 | 1    | 0    | 高    |
| Mode 3 | 1    | 1    | 高    |
# ADC
ADC是Analog-to-Digital Converter，即模数转换器。它把连续的模拟电压转换成数字量。
## ADC工作模式
**单次传唤**：触发一次，转换一次。
**连续转换**：一次启动后，连续转换。
**扫描模式**：自动依次转换多个ADC通道。
**规则通道**：程序正常顺序转换
**注入通道**：优先级较高，可以在规则转换期间插入转换。
## 数据对齐
ADC数据是12位精度的，但是数据是存储在16位数据寄存器中，所以ADC的存储结果可以分为左对齐或右对齐两种方式
## ADC校准
ADC有一个内置自校准模式。校准可大幅减小因内部电容器组的变化而造成的准精度误差。在校准期间，在每个电容器上都会计算出一个误差修正码(数字值)，这个码用于消除在随后的转换中每个电容器上产生的误差。
通过设置ADC_CR2寄存器的CAL位启动校准。一旦校准结束，CAL位被硬件复位，可以开始正常转换。建议在上电时执行一次ADC校准。校准阶段结束后，校准码储存在ADC_DR中。
```c
HAL_ADCEx_Calibration_Start(&hadc1);
```
## 触发转换
**外部触发**：ADC_CR2 的ADON控制 ；定时器捕获；EXIT
**中断触发**：规则 / 注入通道转换结束（转换完一次即进入中断）；模拟看门狗状态位被设置（当转换的模拟电压值低于低阈值或高于高阈值时，便会产生中断。阈值的高低值由ADC_LTR和ADC_HTR配置）
**DMA触发**：规则 / 注入通道转换结束后会产生DMA请求（只有ADC1和ADC3可以）
# DMA
DMA是Direct Memory Access，即直接存储器访问。
DMA可以在不需要CPU逐个搬运数据的情况下，实现：
- 外设到内存；
- 内存到外设；
- 内存到内存
的数据传输。
12个独立的可配置的通道(请求)：DMA1有7个通道，DMA2有5个通道。
# 看门狗
WDG（Watchdog）看门狗可以监控程序的运行状态，当程序因为设计漏洞、硬件故障、电磁干扰等原因，出现卡死或跑飞现象时，看门狗能及时复位程序，避免程序陷入长时间的罢工状态，保证系统的可靠性和安全性。
本质是一个定时器，当指定时间范围内，程序没有执行喂狗（重置计数器）操作时，看门狗硬件电路就自动产生复位信号。
STM32内置两个看门狗。独立看门狗（IWDG）和窗口看门狗（WWDG）.
### 独立看门狗
IWDG使用LSI独立低速时钟。
特点：
- 独立于主系统时钟；
- 主时钟异常时仍可能工作；
- 一旦启动通常不能由软件关闭；
- 可靠性较高；
- 适合系统故障恢复。
### 窗口看门狗
WWDG要求程序在规定的时间窗口内喂狗。通常被用来监测，由外部干扰或不可预见的逻辑条件造成的应用程序背离正常的运行序列而产生的软件故障。WWDG通常依赖APB时钟。
### 对比
|对比项|IWDG|WWDG|
|---|---|---|
|时钟源|独立LSI|APB相关时钟|
|是否独立于主时钟|是|否|
|喂狗时间|超时前即可|必须在窗口内|
|检测过早喂狗|不能|可以|
|可靠性用途|系统防死机|运行节奏监控|
|启动后关闭|通常不能|根据配置控制|
# 综合面试题
## STM32上电后如何进入main函数？
CPU从向量表读取MSP初值和 `Reset_Handler` 地址，执行启动代码，完成 `.data` 复制、`.bss` 清零、系统初始化和C运行库初始化，最后调用 `main()`。
## STM32F103的72 MHz如何产生？
常见方式是8 MHz HSE经过PLL 9倍频。
## 为什么APB1为36 MHz，TIM2却可能是72 MHz？
当APB1预分频不为1时，APB1定时器时钟为PCLK1的2倍。
## 中断中可以使用HAL_Delay吗？
通常不应该。`HAL_Delay()`依赖SysTick更新计数，如果当前中断优先级高于或阻塞了SysTick，延时可能无法结束；同时中断中阻塞会严重影响系统实时性。
## I²C为什么需要上拉，UART为什么通常不需要？
I²C采用开漏输出，不能主动输出高电平，所以需要上拉。UART TX通常是推挽输出，可以主动输出高低电平。
## SPI为什么比I²C通常更快？
SPI使用独立发送、接收和时钟线，协议开销较小，不需要设备地址和逐字节ACK，能够实现全双工高速传输，但占用引脚更多。

## ADC分辨率和精度有什么区别？
分辨率表示理论量化等级，例如12位ADC有4096级；精度表示实际测量值与真实值的接近程度，会受到参考电压、噪声、非线性和采样电路等因素影响。
## DMA的作用是什么？
DMA自动在外设和内存之间搬运数据，减少CPU逐个处理数据的负担。CPU仍负责配置、启动、数据处理和错误管理。
